- 修复多个凭证存储实例及首次保存时整份 vault 覆盖的问题：同进程共享事务锁，读取持久化权威快照后合并并同步保存，成功才更新缓存与版本。
- 凭证读取失败不再视为空 vault；更新失败不再删除旧项后重建；删除使用 tombstone，防止残留旧单项凭证重新迁入。
- 配置不可解码时，在覆盖前独立保留原始字节；普通保存、后续启动及默认快照恢复不清除归档，保留人工恢复依据。
- Profile 文件从创建起使用 0600 权限，私有暂存后原子替换；应用专属目录使用 0700，既有文件尽可能收紧权限，拒绝符号链接和硬链接目标。
- 将父刷新取消传递到 detached worker；合作式任务能响应取消，非合作式任务晚返回也不会发布失效结果或覆盖新一轮刷新。
- 移除全生命周期 0.75 秒窗口扫描 Timer，保留窗口事件及有限扫描；Grok/Gemini 文件枚举缓存跨服务实例复用，不改变时间范围语义。
- 官方服务设置统一管理订阅与 API 来源，服务名后标注 API 类型；根据来源展示账号、套餐额度或账户余额，保留现有服务配置。
- 统计页标题、刷新提示、指标、供应商/模型选项、空态、月份和固定来源说明跟随应用语言；未知诊断保留原文。
- 新增隔离构建入口，产物按 checkout 分开并默认放在同步目录外；不修改全局 Xcode 选择。CI 检查生产源码警告，Release workflow 打包前运行测试。
- 修复发布测试的计时不稳定：保存提示测试使用可控时钟验证原始截止时间、旧任务取消和延迟补偿，不再依赖毫秒级真实等待；应用默认仍使用系统时间和原有等待方式。

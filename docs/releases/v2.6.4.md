### English

- HTTP validation unification is complete: the remaining 12 call sites (Qwen, Ollama, Trae, Amp, Grok relay, Z.ai, Kimi relay, Moonshot, Windsurf, Microsoft Copilot, OpenCode Go, Cursor session refresh) moved to the shared layer. Every provider now classifies 401/403 → unauthorized, 429 → rate-limited, 408/5xx → timeout, HTML-in-JSON → invalid response, and the 429 Retry-After header is honored on all official and relay channels (capped at one hour).
- Credential write-backs are observable: the four production paths that persist refreshed OAuth tokens to local credential files, plus the Codex/Claude vault write-backs, no longer swallow failures silently — everything is logged.
- A shared `OAuthRefreshPipeline` unifies the Codex/Claude desktop refresh chain (parameterized endpoint, field mapping, file and vault write-backs; write-back failures never fail an otherwise successful refresh) and is exposed on both desktop auth services for the account layer.
- Config robustness: `AppConfig` gains `schemaVersion` (currently 3) and field-level enum fallback — unknown enum values from hand-edited or downgraded configs (language, resource mode, status bar style, provider source/display modes, 11 fields total) fall back to defaults with a startup diagnostic instead of invalidating the whole config. Provider identity and credential-kind enums stay strict; structural corruption still goes through the archive-and-recover path.
- Formatting convergence finished: the last four NumberFormatter constructions (status bar, menu cards, quota display, relay parsing) moved to the shared implementation after byte-for-byte output comparison.
- Docs: PROVIDERS.md gains Trae, OpenRouter (Credits/API), Ollama Cloud, Microsoft Copilot, and Z.ai (API) entries; copy-audit.md is marked as an archived snapshot. The 1,093-line LocalUsageHistoryRepository was split into four focused files with zero behavior change.
- Full suite: 1,460 tests, 0 failures (34 new); clean build with zero code warnings. The provider polling layer keeps its own refresh chain this release (observability added only); full switchover to the pipeline lands next release. Local package is ad-hoc signed and not notarized; published artifacts follow the GitHub Release workflow.

- 会话 Cookie 类站点统一自动续期：浏览器优先或自动导入模式下，每 30 分钟从浏览器重新导入一次登录态，在过期前换上新的 Cookie；30 分钟内不再触浏览器。
- 覆盖小米 MIMO、MiniMax、爱琳语等中转站，以及千问、Ollama、OpenCode Go，还有 Codex 与 Claude 的网页模式。浏览器没有更新的登录时继续使用仍有效的旧凭证，不会把轮询弄失败。
- 服务器拒绝旧凭证后立刻再读一次浏览器并重试；完全读不到登录时的等待从 10 到 15 分钟统一收成 1 分钟，Trae 也是 1 分钟。
- 手动优先与手动粘贴模式保持不变，只用你保存的那份；过期报错统一说明如何切到浏览器优先，或重新粘贴。
- 同时支持 API 密钥与 Cookie 的通用中转模板不做自动轮换，避免后台读取把你粘贴的密钥换掉。

### 验证与边界

- `RelayProviderTests`、`QwenProviderTests`、`OllamaCloudProviderTests`、`OpenCodeGoProviderTests`、`OfficialProviderTests`、`TraeProviderTests` 全部通过；arm64/x86_64 Release 打包通过，并已覆盖安装到本机 `/Applications/oh-myusage.app` 后正常启动。
- 自动续期的前提是浏览器里该站点保持登录，且使用 Chrome、Arc、Edge 等 Chromium 系浏览器；Safari 与 Firefox 的登录读不出来。浏览器会话本身掉了，仍需重新登录一次。

### English

- Session-cookie sites now renew themselves the same way: in Browser First or auto-import mode the app re-reads the browser every 30 minutes and swaps in a newer login before the saved cookie expires, then leaves the browser alone until the window opens again.
- Applies to Xiaomi MIMO, MiniMax, Ailinyu and the other cookie-based relays, plus Qwen, Ollama, OpenCode Go, and the web modes of Codex and Claude. When the browser has nothing newer, the saved cookie keeps working.
- A rejected credential is retried against the browser immediately, and the wait after a browser with no login is unified to 1 minute, including Trae.
- Manual First and pasted credentials are unchanged and are never replaced. Generic relay templates that also accept an API key are not rotated, so a background read cannot overwrite a key you pasted.
- `RelayProviderTests`, `QwenProviderTests`, `OllamaCloudProviderTests`, `OpenCodeGoProviderTests`, `OfficialProviderTests`, and `TraeProviderTests` pass. The universal Release package builds and was installed over `/Applications/oh-myusage.app` on the release machine.
- Renewal needs the site to stay logged in inside a Chromium browser (Chrome, Arc, Edge); Safari and Firefox logins cannot be read, and a logged-out browser session still needs one manual login. API keys and logins stored inside another app's own data cannot be renewed here. OAuth refresh-token providers already renewed themselves and are unchanged.
- The local package is ad-hoc signed and not notarized; signing, notarization, and the published artifacts follow the GitHub Release workflow.
